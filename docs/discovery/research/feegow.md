# Feegow Clinic — notas de investigación

- **Proveedor:** Feegow (grupo Docplanner, Brasil).
- **URL oficial:** https://feegowclinic.com.br/precos-e-planos
- **Fecha de consulta:** 2026-11-21
- **Secciones leídas:** precios y planes (Starter, Plus, VIP), home, certificaciones.
- **Nivel de evidencia:** funcionalidad y precio comprobados.

## Datos verificados

- Precios por profesional/mes: **Starter R$ 129**, **Plus R$ 199**, **VIP R$ 249** (Black Friday VIP R$ 174,30). Prueba gratuita.
- Starter: perfil básico Doctoralia, **agenda múltiple**, **TISS**, control financiero.
- Plus: agrega gestión de glosas, reportes personalizados, **firma digital**.
- VIP: agrega **Noa Notes** (asistente IA), integración con prontuario, modelos personalizables, **NFS-e** (sujeta a viabilidad del municipio).
- Declara **certificación SBIS NGS2**, AWS y LGPD; API e interoperabilidad; telemedicina.
- Campaña de marketing: "reducción de no-shows garantizada".

## Nota crítica

Es el referente brasileño de facturación TISS y certificación de datos. Su fortaleza administrativa no tiene equivalente argentino, pero no cubre odontología clínica.
