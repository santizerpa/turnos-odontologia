# Tasks

> Orden TDD: en cada grupo se escribe primero el caso de prueba rojo con `node:test`, se implementa el mínimo para hacerlo pasar a verde y se refactoriza con la suite en verde; la fase `apply` ejecuta el ciclo completo. Esta fase de propuesta no ejecuta builds, tests ni el servidor.

## 1. Preparación del frontend

- [ ] 1.1 Crear `frontend/tsconfig.admin.json` (`rootDir: src/admin`, `outDir: dist/js/admin`) y ajustar `frontend/package.json` con un build que emita el bundle público y el administrativo, además de un script `test` que compile TypeScript y ejecute `node --test` sobre los `*.test.js` generados, sin agregar dependencias; verificar que `npm run build` produce `dist/js/admin/main.js` y que `npm test` ejecuta también los tests ya existentes en `frontend/src/public-reservation/`.
- [ ] 1.2 Cambiar `frontend/admin.html` para cargar `/js/admin/main.js` en lugar de `/main.js`; verificar que el HTML compilado en `dist/admin.html` no contiene `/main.js` y que el bundle público queda intacto.
